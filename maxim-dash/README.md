# Maxim Dash

Eigenständiger HTML5-Prototyp ohne Musik.

## Enthalten

- Cube, Ship, Ball, UFO, Wave, Robot, Spider und Swing
- Dual-Portal mit zweitem kontrollierten Icon
- Mini-Größe und fünf Geschwindigkeiten
- Mode-, Size-, Speed- und Gravitätsportale
- Coins und Checkpoints
- Training mit Checkpoints und Geschwindigkeitsänderung
- JSON-Level speichern/laden
- Level-Editor für Blöcke, Spikes, Schrägen, Portale und weitere Objekte
- Touch/Klick/Space-Eingabe
- lokale Modus-Statistiken

## Start

`index.html` im Browser öffnen.

Das Projekt ist eine eigenständige Umsetzung und verwendet keine Geometry-Dash-Assets, Levels oder Musik.
